Privacy at Chevelon Software

Chevelon Software builds products with a strong respect for user privacy. This page explains the privacy practices that apply to our current products.

Chevelon Software Privacy Policy

Effective Date: August 2026

RepGuide

Data Stored on Your Device

RepGuide does not require an account. Workout content remains stored locally on the user's device. Workout data includes workouts, machines, weights, repetitions, notes, settings, and history.

Device security such as a passcode or biometric protection helps protect locally stored workout history.

Usage and Diagnostic Data

RepGuide sends limited feature-use analytics and technical crash and error diagnostics to PostHog to help improve reliability. Crash and error reports may include the technical error type and message, a stack trace, app version and build, platform, device and operating system information, other technical environment information, and anonymous event or session identifiers used by the diagnostics service.

RepGuide does not intentionally attach workout details, workout names, machine names, weights, reps, sets, notes, other user-entered workout content, or identity to these analytics or diagnostics.

Client IP data is discarded, and location is not inferred from IP addresses. Session replay is off. This app does not use advertising or cross-app tracking.

Advertising and Cross-App Tracking

This app does not use advertising or cross-app tracking.

Local Data Management

Workout reminders are scheduled locally on the user's device.

WeightSpan

Data Stored on Your Device

WeightSpan is a local-first Android app. Core weight, profile, and reminder data is stored locally on the device. WeightSpan has no user accounts and does not sync that data to Chevelon Software.

Weight entries, profile information, reminder settings, and related history remain on the device unless the user chooses to export data.

Usage and Diagnostic Data

WeightSpan sends limited feature-use analytics and technical crash and error diagnostics to PostHog to help improve reliability. Crash and error reports may include the technical error type and message, a stack trace, app version and build, platform, device and operating system information, other technical environment information, and anonymous event or session identifiers used by the diagnostics service.

WeightSpan does not intentionally attach entered weight, BMI, height, weigh-in dates, notes, reminder details, or other health information entered by the user to these analytics or diagnostics.

Client IP data is discarded, and location is not inferred from IP addresses. Session replay is off. This app does not use advertising or cross-app tracking.

Advertising and Cross-App Tracking

This app does not use advertising or cross-app tracking.

Local Data Management

CSV exports are created at the user's request and are handled through the location or app the user chooses when exporting.

Additional Policy Information

Children's Privacy

RepGuide is not directed toward children under 13.

Future Features

If future versions introduce cloud backup, account synchronization, AI coaching, or materially different data practices, this policy will be updated before those features are made available.

Changes to This Policy

The Effective Date identifies the latest version of this policy.
